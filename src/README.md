
# Stardust Ultra
## Professional-Grade Knowledge Management System

**Stardust** is ImperialX's flagship local-first note-taking application designed for desktop environments with sophisticated cognitive frameworks for organizing, analyzing, and visualizing knowledge networks.

### Key Features

#### 🌌 Orbital Mode (Force-Directed Knowledge Graph)
- Custom physics engine with gravitational mass based on semantic connections
- Temporal decay algorithms for peripheral zone identification
- Semantic clustering and bridge note suggestions
- Quadtree optimization for 5,000+ node performance

#### 📊 Matrix Mode (Strategic Evaluation Engine)
- Impact vs. Effort coordinate mapping
- Automated pruning for thankless tasks
- Ghost layers for MoSCoW/SWOT overlays
- Strategic decision framework

#### 📅 Timeline Mode (Sequential Momentum Tracking)
- Context switching detection
- Project velocity calculation
- State-diff snapshots for historical rewinding
- Interstitial journaling prompts

#### 🔍 Prism Mode (Advanced Spectral Refraction)
- Automatic content decomposition into 4 wavelengths:
  - **Red (Action)**: Tasks, deadlines, executables
  - **Blue (Strategy)**: Goals, vision, reasoning
  - **Green (Resource)**: Data, links, references
  - **Violet (Counter-Perspective)**: Adversarial challenge generation

### Architecture & Premium UI

- **Local-First**: IndexedDB via Dexie.js for offline-capable persistence.
- **Multi-threaded**: Web Workers for physics calculations and heavy processing.
- **Reactive**: Zustand-based state management optimized for 120fps canvases.
- **Modular**: Clean separation of concerns with TypeScript interfaces.
- **Premium macOS-style Dock**: Glassmorphic sidebar navigation with responsive spring-animated haptics.
- **Spring Tooltips**: Detailed shortcuts popup (`⌘ K`, `P`, `L`, `S`) on button hover via Framer Motion.
- **Legibility Boost**: Global contrast enhancements for low-light environments.

### Technical Highlights

- Zero external dependencies for core functionality.
- Handles 5,000+ nodes with smooth physics calculations.
- Code-split asset bundle for fast initial page load (Framework, Animation, Vendor).
- Sophisticated computational geometry algorithms.
- Graduate-level engineering rigor in implementation.
